# Joeven — Learn Autonomous AI Agents

A guided academy for building **autonomous AI agents**. Live at [joeven.com](https://joeven.com).

## Curriculum

- Getting Started, Python, Mathematics
- Machine Learning, Transformers, LLMs
- Prompting, Tools & function calling, RAG & memory
- Agent architectures, Multi-agent systems
- Evals & safety, Production
- 5 portfolio projects, exercises, quizzes, certificates

Python in the browser runs via [Pyodide](https://pyodide.org) (no server).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

## Deploy

The app is a Next.js site. Production is intended for **Vercel** with the custom domain `joeven.com`.

1. Push to GitHub (`PVengalRaoP/joeven`)
2. Import the repo in Vercel
3. Add domain `joeven.com` (and `www`) in the Vercel project

Optional env:

- AdSense client id — swap the `AdSlot` placeholder
